# About

I build systems and then look for where they'll break. Most of my work sits between machine learning, data, and verification: training a model is the easy part, the harder part is proving the number on the readme is actually true.

Examples from recent work: doubled a YOLOv8 detector's mAP@50 by tracing a degraded pipeline back to annotation errors and an NMS misconfiguration. Caught a label-construction defect that would have let 105K corrupted targets into a flight delay model. Built validation gates (null counts, class distribution checks, leakage audits) that run before training even starts, not after.

I'm comfortable on either side of that line: building the model, or finding the reason it shouldn't be trusted yet.
